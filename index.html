Scientific Workbench

A Solidarge desktop application

A calculation starts with a structure. Workbench brings the structure, calculation settings and output into one working environment, with Nanoworks handling the calculations.

Prepare a structure
Build or import an atomic structure in the Builder, then pass it to a calculation window.
Set up a calculation
Choose the calculation tasks and review the Nanoworks input. Your structure and input files remain accessible.
Work with the output
Follow calculation logs and examine the results alongside the files that produced them.

Built around Nanoworks

Scientific Workbench is Solidarge’s proprietary desktop product. Its calculation workflows use Nanoworks, an independent open-source command-line tool for materials simulation.

Nanoworks can also be used on its own.
